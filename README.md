# Modern Developer Portfolio 🌌

A high-fidelity, interactive developer portfolio built with React, Framer Motion, and Tailwind CSS. Featuring a premium "glassmorphism" aesthetic, dynamic network background, and focused professional storytelling.

## ✨ Key Features

- **Premium Glassmorphism UI**: High-fidelity translucent cards and modals with backdrop blurring.
- **Dynamic Network Sphere**: A custom-rendered HTML5 Canvas background that responds to interaction.
- **Interactive Project Modals**: Flagship projects (RiskLens, AI OS, TrustChain) feature deep-dive modals with detailed info and links.
- **Founder-Vibe Messaging**: Clear, concise, and professional copy focused on AI, Blockchain, and Scalable Systems.
- **Responsive Navigation**: Smooth internal scrolling and a minimal, text-focused desktop/mobile experience.

## 🛠️ Technology Stack

- **Frontend**: React.js, Vite
- **Styling**: Tailwind CSS, Vanilla CSS
- **Animations**: Framer Motion
- **Graphics**: HTML5 Canvas (2D API)
- **Deployment**: Configured for streamlined GitHub deployment.

## 🚀 Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/HemeshKanyal/Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
